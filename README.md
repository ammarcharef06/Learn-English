# 🎓 أكاديمية الإنجليزية — Learn English

موقع تعليمي شخصي لتعلّم اللغة الإنجليزية من الصفر حتى المستوى المتوسط (A1 → B1)، بواجهة عربية RTL،

مع إشعارات تذكيرية حقيقية عبر **OneSignal**.

> 🔗 الرابط بعد النشر: **https://ammarcharef06.github.io/Learn-English/**
> 🔐 كلمة المرور الأولية: **`SAYPER`** (غيّرها من الإعدادات ← الأمان)

## 🚀 التشغيل المحلي (للمعاينة قبل النشر)

الموقع لا يحتاج أي تثبيت أو بناء، فقط خادم ملفات ثابت:

```bash
# من داخل مجلد المشروع
python -m http.server 5173
# ثم افتح: http://127.0.0.1:5173
```

> ⚠️ لا تفتح `index.html` بالنقر المزدوج (بروتوكول `file://`)، لأن المتصفح يمنع تشغيل الوحدات (ES Modules)
> وإشعارات المتصفح في هذا الوضع.

### فحوصات المشروع

```bash
node tools/check.mjs        # سلامة الملفات والاستيرادات والبيانات + فحوصات قسم A0
node tools/test-logic.mjs   # ٩٢ اختباراً منطقياً: المصادقة، الأسئلة، SRS، الإشعارات، النسخ الاحتياطي

npm test                    # يشغّل الثلاثة معاً (check ثم test-zero)
```

> بوابة النشر في `.github/workflows/deploy.yml` تُشغّل `check.mjs` و`test-zero.mjs` تلقائياً قبل كل نشر،
> فلا يصل إلى GitHub Pages أي كسر في المحتوى أو الاستيرادات.

## 🌱 قسم «من الصفر» (A0) — دليل سريع

### كيف يصل إليه المتعلّم؟

| المدخل | التفاصيل |
|---|---|
| **شاشة الاختيار عند الدخول** | تظهر **مرة واحدة** في أول دخول: «أبدأ من الصفر (A0)» أو «عندي أساس — ابدأ من A1» أو «أرني الاثنين». يُحفظ الاختيار في `settings.zero.onboarded` ولا تتكرر. ويمكن إعادة عرضها من زر «🔁 أعد شاشة الاختيار» في صفحة القسم |
| **زر التبديل الدائم** | زر **`A0`** في الشريط العلوي موجود في **كل صفحات الموقع** (يحمل `aria-pressed`)، يُبدّل وضع «من الصفر» فيُقدّم القسم في القائمة والرئيسية، ويُحفظ فوراً |
| **خانة التنقّل البارزة** | بطاقة متدرّجة اللون في **مقدمة القائمة الجانبية** تعرض نسبة الإتقان وعدد المراحل والحروف، + خانة **`A0`** أولى في شريط التنقل السفلي، + **لافتة بارزة** أعلى لوحة التحكم |
| **المسارات** | `#/zero` (الرئيسية) · `#/zero/stage/<id>` (المرحلة) · `#/zero/drill/<id>` (تدريب المرحلة) · `#/zero/pad` (لوح الكتابة) · `#/zero/exam` (الاختبار النهائي) · `#/zero/certificate` (الشهادة) |

### المراحل الثمانية

| # | المرحلة | العناصر |
|---|---|---|
| ١ | 🔤 الحروف وأصواتها | ٢٦ حرفاً: الاسم · الصوت · كلمة لكل حرف · نصيحة نطق |
| ٢ | 🔡 الحروف المركّبة | `sh · ch · th (مهموسة/مجهورة) · ph · ck · ng · oo · ee · ea · ou` |
| ٣ | 🔢 الأرقام | ٠–٢٠ + العشرات + ١٠٠ + الأرقام الترتيبية (١٠) |
| ٤ | 📅 الأيام والشهور والوقت | ٧ أيام · ١٢ شهراً بفصولها · ٤ فصول · عبارات الوقت · ٨ صيغ للساعة |
| ٥ | 🙋 الضمائر و `to be` | ٨ ضمائر + `am/is/are` بثلاثة أمثلة لكل صيغة |
| ٦ | 🧺 أول ١٢٠ كلمة | ٨ مجموعات × ١٥ كلمة (عائلة · جسم · طعام · ألوان · حيوانات · مدرسة · بيت · أفعال) |
| ٧ | 💬 أول ٤٠ جملة | تحيات · تعريف · عائلة · مدرسة · يوميات · أسئلة · تسوّق · مجاملة |
| ٨ | 📖 قراءة وكتابة أولى | ٤ نصوص قصيرة (٥–٧ أسطر) مع ٣–٤ أسئلة فهم لكل نص |

### المزايا التفاعلية

- **نطق عربي مكتوب** لكل حرف وكلمة وجملة وسطر قراءة (مثال: `mother` → «مَاذَر»).
- **صوت تلقائي متسلسل**: شريط ▶ تشغيل / ⏸ إيقاف / 🐢 تباطؤ ينطق عناصر المرحلة بالترتيب ويميّز العنصر الحالي، وزر 🐢 لكل بطاقة على حدة.
- **لوح كتابة تفاعلي** (`#/zero/pad`) باللمس أو القلم أو الفأرة مع خطوط توجيه رباعية، ووضعان: **مطبوع** و**متصل**، وقلم/عريض/ممحاة/تراجع/مسح، ودليل شفاف للتتبّع، وربط مباشر مع 🔊 النطق.
- **إتقان يدوي وتلقائي**: زر «✅ أتقنت» لكل عنصر، ويُسجَّل الإتقان تلقائياً عند الإجابة الصحيحة في التدريبات.
- **تدريب ٥ أسئلة بعد كل مرحلة**: يُسجَّل كل محاولة، وتُعتبر المرحلة مكتملة عند **٨٠٪** أو أكثر.
- **اختبار نهائي من ٣٠ سؤالاً** موزّعة على المراحل الثمانية (يُبنى عشوائياً في كل محاولة، بلا حد للمحاولات).
- **١٣ شارة تأسيس** (أول مرحلة · ٢٦ حرفاً · المركّبة · الأرقام · الوقت · الضمائر · ١٢٠ كلمة · ٤٠ جملة · القراءة · كل المراحل · ٩٠٪ · ١٠٠٪ · الشهادة).
- **شهادة تأسيس** باسم المتعلّم ورقم شهادة فريد (`A0-XXXX-000`) وتاريخ استحقاق، قابلة للطباعة/الحفظ PDF، مع شروط واضحة قبل الاستحقاق.
- **توصية بلا قفل**: عند إتمام المراحل + إتقان الحروف + ٩٠٪ في الاختبار تظهر توصية صريحة بالانتقال إلى A1 — وكل المستويات تبقى **مفتوحة دائماً** ولا يوجد أي قفل.
- **تصفير مستقل**: «↺ تصفير تقدّم قسم A0» يمسّ `progress.zero` فقط، ولا يمسّ تقدّم A1/A2/B1 ولا النقاط.

## 🎨 ستايلات الواجهة (Skins)

الموقع يدعم ثلاثة ستايلات كاملة، تُطبَّق فوراً دون إعادة تحميل:

| الستايل | الوصف | الوضع |
|---|---|---|
| **Kali GNOME** (الافتراضي) | داكن بلون كالي الأزرق `#2777ff`، بطاقات مسطّحة بزوايا 12px، شريط جانبي كقائمة GNOME | داكن دائماً |
| **GNOME Adwaita** | ألوان GNOME الرسمية: فاتح `#fafafa` وداكن `#242424` مع الأزرق `#3584e4` | فاتح/داكن/تلقائي |
| **الكلاسيكي** | الستايل الأكاديمي الأزرق/البنفسجي السابق | فاتح/داكن/تلقائي |

**كيف تبدّل؟**
- **زر 🎨 في الشريط العلوي**: يبدّل بالتتابع كالي ← GNOME ← الكلاسيكي.
- **الإعدادات ← ستايل الواجهة**: اختيار مباشر مع زر الفاتح/الداكن (يُعطَّل تلقائياً في ستايل كالي لأنه داكن دائماً).
- التبديل فوري ويُحفظ في جهازك.

**كيف تضيف ستايلاً جديداً؟**
1. أنشئ ملفاً في `assets/css/skins/` واكتب قواعده بادئةً بالمحدّد `html[data-skin="اسمك"]`.
2. أضف رابطه في `index.html` بعد `main.css`.
3. أضف عنصراً في مصفوفة `SKINS` داخل `assets/js/views/settings.js`.
4. أضف الملف إلى قائمة `CORE` في `service-worker.js` ليعمل بلا إنترنت.

> التقنية: النظام كله متغيّرات CSS (`--brand-1`, `--surface`, `--radius`…) لذا أي ستايل جديد = ملف صغير يبدّل المتغيّرات وبعض تفاصيل المكوّنات، **بلا أي مكتبة خارجية وبلا خطوة بناء**.

## 🔔 إعداد OneSignal (الإشعارات الحقيقية التي تعمل والموقع مغلق)

1. ادخل إلى [onesignal.com](https://onesignal.com) وأنشئ حساباً مجانياً.
2. **New App/Website** ← الاسم: `Learn English` ← اختر منصة **Web**.
3. اختر **Typical Site** ثم أدخل رابط موقعك:
   `https://ammarcharef06.github.io/Learn-English/`
4. في خطوة الـ SDK اختر **Custom Code** (المشروع يحتوي أصلاً على كل الملفات المطلوبة).
5. انسخ **App ID** (يبدو مثل `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`).
6. افتح الموقع ← **الإعدادات ← الإشعارات والتذكير ← OneSignal App ID** ← الصق المعرّف ← **حفظ**.
7. اضغط **🔔 تفعيل إشعارات Push** ← اسمح بالإشعارات عند طلب المتصفح.
8. اضغط **إرسال إشعار تجريبي** للتأكد، ثم أرسل من لوحة OneSignal رسالة لأجهزتك.
9. لمعرفة معرّف اشتراك جهازك (لإرسال إشعار موجّه إليه من لوحة OneSignal): **الإعدادات ← 📋 نسخ معرّف اشتراكي**.

> 💡 **لتفعيل الإشعارات تلقائياً على كل أجهزتك** دون إدخال المعرّف في كل جهاز:
> افتح ملف `assets/js/config.js` وضع المعرّف في السطر:
> `window.LEA_ONESIGNAL_APP_ID = 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx';`
> ثم ارفع التعديل (`git push`). هذا المعرّف **ليس سراً** — هو معرّف عام لتطبيقك، ويظهر في الإعدادات أيضاً.

> 🔁 **تذكير يومي تلقائي بدون فتح الموقع:** أنشئ رسالة من نوع Push في لوحة OneSignal ← **Schedule** ← اختر الوقت والتكرار (يومي) ← Audience: All Subscribers.
> أما التذكير داخل الموقع (مع كلمة اليوم وسلسلتك) فيعمل تلقائياً دون أي إعداد.

**ملاحظات مهمة:**
- الملفان `service-worker.js` (مدمج فيه SDK) و `OneSignalSDKWorker.js` موجودان في جذر المشروع جاهزَين.
- الإشعارات تعمل على **HTTPS** فقط (GitHub Pages يوفّر ذلك تلقائياً).
- على الآيفون: يجب تثبيت الموقع كتطبيق أولاً (سفاري ← مشاركة ← إضافة إلى الشاشة الرئيسية) ثم تفعيل الإشعارات.
- التذكير اليومي المحلي يعمل حتى بدون OneSignal (يظهر عند فتح الموقع أو تثبيته).

## 🔐 كلمة المرور والأمان

- **كلمة المرور الأولية:** `SAYPER` (اختُرِت عند التخطيط للمشروع وتُخزَّن كبصمة `SHA-256`).
- تُخزَّن البصمة في `localStorage` **داخل جهازك فقط**، ولا تُرسل إلى أي خادم.
- تغييرها: **الإعدادات ← الأمان ← تغيير كلمة المرور** (يُضاف Salt ويُكرَّر التهشير ١٢٠٠٠ مرة).
- حماية من التخمين: بعد ٥ محاولات خاطئة يتوقف الدخول مؤقتاً (١٥ ثانية وتتضاعف).
- نسيان كلمة المرور؟ **الإعدادات ← إعادة كلمة المرور الأولية** تُرجعها إلى `SAYPER`.
  وإن قفلت عليك تماماً: افتح أدوات المطوّر في المتصفح (F12) ← Console ← نفّذ:
  ```js
  localStorage.removeItem('lea.auth.v1'); localStorage.removeItem('lea.session.v1'); location.reload();
  ```
- زر 🔒 في الشريط العلوي يقفل الموقع فوراً. وخيار «تذكّرني» يبقي الجلسة ٣٠ يوماً على جهازك الخاص.

> هذه حماية مناسبة لموقع شخصي، لكنها ليست حماية بنكية: الموقع ثابت (Static) وكل المحتوى موجود في المتصفح.
> لا تضع فيه بيانات حساسة.

### إصلاحات جانبية ظهرت أثناء التحقق في متصفح حقيقي

| العطل | الإصلاح |
|---|---|
| سمة `hidden` لم تكن تُخفي أزرار الشريط العلوي (`.icon-btn{display:grid}` كان يتغلّب عليها) | قاعدة `[hidden]{display:none!important}` في طبقة `reset` |
| `.topbar-opt` (إخفاء الأزرار الثانوية على الهواتف) لم يكن يعمل لنفس السبب | `!important` داخل استعلام الوسائط |
| أزرار الشريط العلوي تجاوزت حافة شاشة 320px بـ٢٦px بعد إضافة زر A0 | تصغير أزرار الشريط والعلامة عند `≤400px` (خارج طبقات CSS لتفوز في التتالي) |
| لوحة شاشة الاختيار كانت تتجاوز عرض الشاشة (شبكة بعرض نسبة مئوية) | `grid-template-columns: minmax(0,1fr)` + `max-inline-size` بدل `min(860px,100%)` |
| مفتاح مضمون مكرّر للضمير `You` (مفرد وجمع) كان يخلط سجل الإتقان | إضافة رقم العنصر إلى المفتاح في `data/zero.js` |
| محاولة تدريب المرحلة كانت تُهمَل إن كانت النتيجة أقل من ٨٠٪ | `recordStageDrill` يسجّل كل محاولة، ويُتمّ المرحلة عند ٨٠٪ فقط |

## 🆘 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| **فتحت الملف بالنقر المزدوج ولا يستجيب أي زر** | هذا متوقع: بروتوكول `file://` يمنع تشغيل JavaScript. الموقع يعرض لك الآن رسالة إرشادية داخل الصفحة، والحل هو تشغيل `python -m http.server 5173` ثم فتح `http://127.0.0.1:5173`، أو نشر الموقع على GitHub Pages |
| الصفحة فارغة أو «تعذّر تشغيل الموقع» | افتح الموقع عبر HTTPS أو `http://localhost`، وتأكد من تفعيل JavaScript في المتصفح |
| التنقل لا يُظهر القسم الحالي | تأكد من أنك على النسخة الأخيرة (أعد تحميل الصفحة)؛ يُفعَّل تمييز القسم الحالي تلقائياً عند التنقل |
| لا يظهر صوت النطق | تأكد من وجود صوت إنجليزي في نظامك (Windows: الإعدادات ← الوقت واللغة ← الكلام)، وجرّب تغيير الصوت من الإعدادات |
| الإشعارات لا تصل | فعّل الإذن من إعدادات المتصفح، وتأكد من إدخال OneSignal App ID، ومن أن الموقع يعمل بـ HTTPS |
| الموقع يعرض نسخة قديمة بعد التحديث | ملفات الكود تُجلب من الشبكة أولاً وتُخزَّن للعمل بلا إنترنت، فأعد التحميل مرة واحدة؛ وإن استمرت المشكلة امسح بيانات الموقع من إعدادات المتصفح |
| تقدمي اختفى | التقدم محفوظ في هذا المتصفح تحديداً؛ استخدم «تصدير نسخة احتياطية» و«استيراد» لنقله بين الأجهزة |
