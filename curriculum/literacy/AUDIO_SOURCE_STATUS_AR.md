# اعتماد صوت Emma وترحيل بنك التسجيلات

آخر تحديث: 2026-10-30
الفرع: development

## الصوت الذي اختاره المستخدم

الصورة المرفقة تعرض الاسم حرفياً: **English - United States - Emma**.

تسجل قائمة Microsoft الرسمية للصوت القياسي الأمريكي المعرّف:
`en-US-EmmaNeural`.
وهذا هو المعرّف الذي سنستخدمه، وليس `en-US-EmmaMultilingualNeural`؛ فهما صوتان مختلفان رغم اشتراكهما في اسم Emma.

مرجع Microsoft: [Language and voice support](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support).

## الحالة الحالية — يجب عدم الخلط

- **الصوت المستهدف من الآن:** Emma — `en-US-EmmaNeural`.
- **التسجيلات المضمّنة القديمة:** Aria — `en-US-AriaNeural` بحسب التزامات Git التاريخية.
- لا يمكن تحويل ملفات Aria إلى Emma بتعديل manifest أو تغيير اسم المتحدث؛ يجب إعادة توليد كل ملف ثم الاستماع إليه وفحصه.
- لهذا السبب سُجلت الحالة على أنها ترحيل معلّق، ولم أزعم أن ملفات MP3 القديمة أصبحت Emma.

## ما أضيف

- مولّد نصوص صوتية جديدة: `scripts/generate-emma-audio.mjs`.
- أمر npm: `npm run audio:emma`.
- يثبت المولد المعرّف `en-US-EmmaNeural` ويحفظ MP3 داخل `assets/audio/zero/` فقط.
- يمنع استبدال ملف قائم دون `--force`.
- لا يدّعي أن الكلام العادي يمثل فونيم IPA منفرداً.

الاستخدام:
```sh
python -m pip install edge-tts
npm run audio:emma -- --text="Hello, world." --out=assets/audio/zero/w/hello-world.mp3
```

## خطة الترحيل المطلوبة

1. إعادة توليد 76 ملفاً أساسياً بالصوت Emma: أسماء الحروف الـ26، كلماتها الـ26، أصوات الحروف المركبة الـ12، وكلمات أمثلتها الـ12.
2. إعادة توليد وفحص كل نصوص خريطة الصوت البالغ عددها 280 مدخلاً، مع إزالة التكرار حيث تتطابق النصوص.
3. إنشاء فونيمات الحروف المستقلة والتمييزات الصوتية بمخطط لغوي صحيح؛ لا يكفي نطق أسماء الحروف.
4. استماع بشري إلى كل ملف، والتحقق من عدم القصّ أو الصمت أو الخطأ في النطق.
5. بعد اكتمال الترحيل فقط، تحديث مصدر بنك الصوت إلى Emma وإزالة علامة legacy Aria.

## القيود

- إصدار نموذج Microsoft الخلفي متغير وغير مثبت؛ لذلك لا نضمن تطابق الموجة الصوتية بين تاريخين.
- راجع شروط Microsoft وحقوق إعادة توزيع المخرجات قبل نشر الملفات الجديدة.
- لا تستخدم Google Translate أو SpeechSynthesis أو أي صوت بديل.
