## ملفات الصوت الحالية

- نقطة التسجيل: `assets/js/core/zero-audio.js`
- خريطة المفردات والجمل: `assets/js/data/zero-audio-map.js`
- مشغل التسجيلات: `assets/js/core/speech.js`
- مجلد الأصول: `assets/audio/zero/`
- التغطية الأساسية: 26 اسم حرف، 26 كلمة مثال، 12 مقطعاً صوتياً للحروف المركبة، و12 كلمة مثال للحروف المركبة، إضافة إلى خريطة تسجيلات الكلمات والجمل.

اسم الحرف، وفونيم الحرف، وكلمة المثال أهداف تعليمية مختلفة. لا يجوز استخدام تسجيل اسم الحرف أو الكلمة لإثبات أن الفونيم نفسه مسجل.

## إعادة التوليد بالصوت نفسه

- معرّف الصوت: `en-US-AriaNeural`.
- عميل التوليد الموثق تاريخياً: `edge-tts` (Python).
- أضيف مولّد محلي للنصوص المنطوقة العادية: `scripts/generate-aria-audio.mjs`.
- الاستخدام:
  ```sh
  python -m pip install edge-tts
  npm run audio:aria -- --text="Hello, world." --out=assets/audio/zero/w/hello-world.mp3
  ```
- لا يستبدل المولد ملفاً موجوداً إلا مع `--force`.
- لا تستخدم `scripts/generate-audio.mjs` لهذا البنك؛ فهو يستخدم Google Translate TTS.
- لا تستخدم SpeechSynthesis في المتصفح؛ فهو يختار صوت الجهاز ولا ينتج أصلاً ثابتاً موحداً.

**قيد فونيمي مهم:** عميل edge-tts أزال دعم SSML المخصص؛ لذلك لا يصح تمرير رموز IPA كنص عادي واعتبار الناتج تسجيلاً فونيمياً دقيقاً. كما أن بعض الحروف الإنجليزية لها أكثر من صوت حسب الكلمة والسياق. لا تُنشأ فونيمات مستقلة للحروف الـ26 آلياً دون تصميم صوتي مناسب ومراجعة بشرية.

## حقوق الاستخدام وحدود التطابق

- يمكن طلب معرّف الصوت نفسه مستقبلاً، لكن لا يمكن ضمان تطابق الموجة الصوتية تماماً إذا حدّثت Microsoft النموذج على الخادم.
- سجل Git لا يحفظ نسخة edge-tts التي استُخدمت أول مرة.
- تحديد مصدر التوليد لا يساوي إثبات حق إعادة توزيع المخرجات؛ راجع شروط Microsoft قبل نشر ملفات جديدة.

## سياسة التشغيل

1. أعد استخدام التسجيل الموجود إذا كان مطابقاً للنص والهدف التعليمي.
2. لا تعِد تسمية تسجيل صوت آخر على أنه Aria.
3. لا تستخدم اسم الحرف أو كلمة المثال بدل تسجيل الفونيم.
4. إذا لم يوجد تسجيل معتمد، لا تشغّل صوتاً بديلاً ولا تمنح إتقاناً سمعياً بناء عليه.

## التحقق

```sh
npm run validate:literacy
```

الفحص يثبت وجود المسارات والملفات واتساق البيانات، ولا يثبت جودة النطق أو التطابق الصوتي أو صلاحية الحقوق. يلزم الاستماع البشري ومراجعة الترخيص قبل اعتماد أي أصل جديد.
