# توليد بنك الصوت الكامل بصوت Emma

الصوت المستهدف حصراً: **English - United States - Emma** — `en-US-EmmaNeural`.

## المتطلبات

- Node.js وPython 3.
- اتصال إنترنت أثناء التوليد.
- تثبيت عميل Edge TTS:

```sh
python -m pip install edge-tts
```

## الأوامر

معاينة دون إنشاء أو استبدال ملفات:

```sh
npm run audio:emma:migrate
```

توليد الملفات النصية الناقصة:

```sh
npm run audio:emma:migrate -- --write
```

إعادة توليد الملفات الموجودة واستبدالها:

```sh
npm run audio:emma:migrate -- --write --force
```

تجربة أول 20 ملفاً:

```sh
npm run audio:emma:migrate -- --write --limit=20
```

توليد فئة محددة:

```sh
npm run audio:emma:migrate -- --write --category=letter_name
```

الفئات النصية: `audio_map_text` و`letter_name` و`letter_example` و`digraph_example`.

## التغطية

يقرأ السكربت `docs/curriculum/EMMA_AUDIO_CONVERSION_MAP.csv` بوصفه مصدر الحقيقة، ولا يخمّن أسماء الملفات أو النصوص. تشمل الخريطة 280 نصاً عاماً، و26 اسم حرف، و26 كلمة مثال للحروف، و12 كلمة مثال للتهجئات المركبة: **344 ملفاً للكلام العادي**.

قبل التوليد يتحقق السكربت من تغطية كل مدخل في `AUDIO_MAP` وكل مسار اسم/مثال في بيان الصوت. ويتوقف عند وجود نقص أو تعارض أو مسار غير آمن. لا يستبدل الملفات السليمة افتراضياً؛ استخدم `--force` فقط لإعادة إنشائها. التوليد متسلسل، والملف المؤقت لا يحل محل الملف النهائي إلا بعد نجاح التوليد والتحقق من حجمه. عند فشل ملف، يكمل بقية القائمة ثم يعرض الأخطاء.

## الفونيمات المستقلة

صفوف `letter_phoneme` و`digraph_phoneme` مستثناة عمداً. نطق رمز IPA أو كتابة مثل `sh` عبر TTS لا ينتج بالضرورة فونيمًا معزولاً صحيحاً؛ هذه التسجيلات تتطلب تسجيلاً فونيتياً متخصصاً ومراجعة بشرية.

## الجودة والحقوق

نجاح السكربت يعني أن طلب التوليد تم بصوت ID المحدد وأن الناتج ليس فارغاً أو صغيراً بصورة غير متوقعة؛ ولا يثبت وحده صحة النطق التعليمي. استمع إلى الملفات، وراجع خصوصاً أسماء الحروف وأصوات `th` و`oo` والنبر والوقفات. لا تعلن اكتمال البنك قبل الفحص السمعي.

عميل `edge-tts` غير رسمي ويستخدم خدمة الكلام عبر Microsoft Edge على الإنترنت. تثبيت Voice ID لا يضمن ثبات النموذج الخلفي أو التطابق الصوتي عبر الزمن. راجع شروط الخدمة وحقوق إعادة التوزيع قبل نشر الملفات.
