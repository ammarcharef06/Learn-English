# ترحيل بنك الصوت إلى Emma

الصوت المستهدف: `English - United States - Emma` — `en-US-EmmaNeural`.

## معاينة

```sh
python -m pip install edge-tts
npm run audio:emma:migrate
```

## التوليد

```sh
npm run audio:emma:migrate -- --write --force
```

للتجربة على أول 20 ملفاً:

```sh
npm run audio:emma:migrate -- --write --force --limit=20
```

الأداة تجمع نصوص خريطة الصوت ذات 280 مدخلاً، وأسماء الحروف، وأمثلة الحروف المركبة. لا تستبدل ملفات الفونيمات المنفردة؛ نطق كتابة `sh` أو رمز IPA كنص عادي لا ينتج فونيمًا معزولاً صالحاً. التشغيل الكامل يستبدل ملفات MP3 الموجودة، لذا استمع إلى الناتج وتأكد من صحة النطق قبل نشره.

لا تضع حالة البنك على أنه Emma قبل إكمال التوليد والفحص السمعي. قد تتغير جودة الصوت أو النموذج الخلفي لدى Microsoft مع الزمن، وشروط إعادة توزيع المخرجات تحتاج مراجعة مستقلة.
